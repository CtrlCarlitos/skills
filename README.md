# skills

Agent skills by CtrlCarlitos, installable with the [`skills`](https://skills.sh) CLI:

```sh
npx skills add CtrlCarlitos/skills -s code-search skill-creator show-me repo-policy release-notes update-docs mp-code-review deliver -a claude-code opencode codex antigravity -g -y --copy
```

| Skill | What it does |
|---|---|
| [`code-search`](skills/code-search/SKILL.md) | Decide how to find code before grepping or opening a file: graft (repo graph) > serena (LSP) > rg > grep, gated on what is actually built and what file types are involved, with anti-loop rules. |
| [`skill-creator`](skills/skill-creator/SKILL.md) | Drop-in fork of Anthropic's skill-creator with Windows fixes (pipe reader, UTF-8 file I/O, `--project-root`, real-skill trigger detection) and eval-validity fixes (contaminated results from an installed same-named skill, harness errors masked as a 0% score). The trigger-eval loop now supports `--harness claude\|codex\|opencode\|agy` (confirmed live, each via that harness's own non-interactive CLI). Pinned upstream commit and patch queue in `vendor/skill-creator/` (disposition and audit findings, including a recorded correction, in `DISPOSITION.md`); `scripts/sync-vendor.sh skill-creator` rebuilds or checks it. Upstream issue anthropics/skills#1827; drop the fork once it lands. |
| [`show-me`](skills/show-me/SKILL.md) | Drop-in fork of HumanLayer's show-me with a cross-platform artifact opener (native Windows, WSL, Linux, macOS, devcontainers) replacing the macOS-only `open` command. User-invoked only (`disable-model-invocation`) — not auto-triggered. Confirmed live (2026-10-18): honored correctly by Claude Code, Codex, and Antigravity; still ignored by OpenCode for this plain-`.agents/skills/` install path despite an OpenCode issue claiming a fix shipped (the fix is scoped to a separate "V2 skills" config, confirmed by direct test). See `vendor/show-me/DISPOSITION.md` and #12. Pinned upstream commit and patch queue in `vendor/show-me/`; `scripts/sync-vendor.sh show-me` rebuilds or checks it. |
| [`repo-policy`](skills/repo-policy/SKILL.md) | Audits a GitHub repo's settings, branch protection (via GitHub Rulesets), release-tag protection, and governance files against a configurable policy (repo override → user policy → built-in default, documented exceptions, "required where applicable" settings). Reports a Markdown gap matrix; applies only itemized, explicitly-approved changes — never a blanket apply. GitHub-only by design. |
| [`release-notes`](skills/release-notes/SKILL.md) | Drafts release notes for an explicit commit range, grounded in real commits and diffs: resolves the range (tags, shallow clones, missing tags all fail loudly), collapses reverted pairs and squash merges, reads the diff of `refactor`/`chore`/`test` commits instead of trusting the label, and matches an existing changelog's format when there is one. Repo-type guides (generic, odoo, phoenix, go, flutter, course, docs) in `references/` cover what counts as breaking/security/upgrade per ecosystem. Draft-only, on demand — never tags, pushes, or publishes. |
| [`update-docs`](skills/update-docs/SKILL.md) | Audits a repo's docs against its code — scoped to a diff/range by default, whole-repo on request — citing the file/line/test that proves each finding, never trusting a doc's own claim. Runs `markdownlint-cli2`/`lychee`/`vale` if installed (vale falls back to a synced Google style when the repo has none), skips any that aren't, and never touches `CHANGELOG.md`, an accepted ADR, or a generated doc's output. Fixes or generates new pages (placed by Diátaxis type) only when explicitly asked. |
| [`mp-code-review`](skills/mp-code-review/SKILL.md) | Fork of Matt Pocock's `code-review`: two-axis review (Standards / Spec) of the diff since a fixed point, run as parallel sub-agents with separate reports. Replaces upstream's dependency on `setup-matt-pocock-skills` (never installed here) with a self-sufficient GitHub/GitLab issue-ref fetch (`scripts/tracker.py`) — no tracker doc required. Pinned upstream commit and patch queue in `vendor/mp-code-review/` (disposition, findings, and a baseline-vs-candidate eval in `DISPOSITION.md`); `scripts/sync-vendor.sh mp-code-review` rebuilds or checks it. |
| [`deliver`](skills/deliver/SKILL.md) | Coordinates a task from read-only discovery through an authorized, confirmed PR merge and safe cleanup — a thin layer over Superpowers' own skills (brainstorming, planning, TDD execution, worktrees, finishing-a-branch), adding only the two-gate authorization model and the piece nothing else covers: diagnosing/fixing red CI, squash-merging once authorized, confirming the merge landed, and cleaning up, past where `finishing-a-development-branch` stops. Builds a repo-owned local-validation contract from the actual CI workflow (no separate local/remote check logic to drift). Invocation and the resume/finish entry point are confirmed live on Codex, OpenCode, and Antigravity (#24); discovery-boundary enforcement is real and comprehensive on Codex, config-dependent (default: none) on OpenCode, and has no comprehensive equivalent on Antigravity's headless CLI — see `references/cross-harness.md`. Hooks/containers/`act`/OS-profile provisioning remain deferred to #23; see `DISPOSITION.md` for the full compatibility audit and eval findings. |

Each skill lives in `skills/<name>/SKILL.md`. Evals sit next to the skill in `evals/`.
